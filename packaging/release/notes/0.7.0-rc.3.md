# Loomle 0.7.0-rc.3

This release candidate completes the SAL v3 object, Domain Target, result, and
stable-reference migration.

## Supported environment

- Unreal Engine 5.7
- macOS on Apple Silicon
- Windows on x64
- Engine-plugin installation

Remove or move any old project-local `Plugins/LoomleBridge` copy before using
0.7. Unreal gives a same-named project plugin precedence over the engine
plugin.

## Compatibility

SAL v3 increments the Client–Bridge protocol from 2 to 3. Install the complete
rc.3 plugin package so the bundled Client and Bridge stay matched. Mixed rc.2
and rc.3 components are rejected instead of attempting an unsafe request.

## Changes since rc.2

- Replaced constructor-shaped values with universal brace ObjectExpr values;
  optional semantic tags are now erasable presentation metadata.
- Unified all six interfaces behind explicit flat
  `target { domain: ... }` declarations and canonical Result Target tables.
- Made native identity Target-relative, including owner-scoped Graph Pins,
  StateTree Parameters, and Blueprint function-local Variables.
- Added explicit related Targets and handoffs for cross-Domain navigation
  instead of nested Targets or implicit capability composition.
- Closed exact, Domain-root, and unresolved Result Text envelopes, including
  strict alias, scope, diagnostic, and object-presence validation.
- Kept legacy syntax only in an explicitly enabled TypeScript compatibility
  reader; public MCP tools and the protocol v3 Bridge are strict.
- Migrated the Client, Bridge, schemas, interface cards, examples, fixtures,
  site, and release gates to the same model.
- Expanded the native suite to 135 UE Automation tests and hardened the exact
  packaged Client-to-Editor mutation, restoration, context, and reconnect path.

## Current limits

- Runtime UI automation, animation/navigation editing, automatic Blueprint
  layout, and cross-Graph execution expansion remain outside this candidate.
- Editor Context returns an explicit unresolved result when the active surface
  has no exact supported Domain Target.

## macOS security notice

This release candidate is not yet signed with a Loomle Developer ID certificate
or notarized by Apple. macOS Gatekeeper may therefore require the user to
explicitly approve the downloaded plugin or Client. Stable Loomle releases will
remain blocked until signing and notarization are part of the exact artifact
path tested before publication.

## Windows security notice

This release candidate is not Authenticode-signed. Windows may therefore show a
trust or SmartScreen warning for the downloaded plugin or Client. Stable Loomle
release policy will be finalized before signed Windows artifacts are published.
