# Loomle 0.7.0

Loomle 0.7 is the first stable SAL v3 release. It gives AI agents one faithful,
text-native interface for reading and changing complex Unreal Editor state
without replacing Unreal Engine's object model.

## Supported environment

- Unreal Engine 5.7
- macOS on Apple Silicon
- Windows on x64
- Engine-plugin installation

Remove or move any old project-local `Plugins/LoomleBridge` copy before using
0.7. Unreal gives a same-named project plugin precedence over the engine
plugin.

## Compatibility

SAL v3 uses Client–Bridge protocol version 3. Install one complete platform
package so the bundled Client and Bridge stay matched. Loomle rejects mixed
protocol versions instead of attempting an unsafe request.

## Highlights

- Added SAL Object Text, Query Text, and Patch Text across Asset, Blueprint,
  Class, Graph, StateTree, and Widget domains.
- Added target-relative stable references, exact related Targets, explicit
  handoffs, contextual diagnostics, and strict Result Text validation.
- Added safe mutation dry runs that share the real parse, resolve, validate,
  and plan path before stopping ahead of apply.
- Added native palette and schema discovery so agents can use Unreal's actual
  actions, types, fields, and defaults without guessing.
- Added project discovery and per-session binding, Editor Context, lifecycle
  recovery, and protocol-aware Client–Bridge health checks.
- Bundled the self-contained TypeScript MCP Client inside each plugin package;
  no separate Python, Node.js, `uv`, global install, or background daemon is
  required.
- Expanded native Unreal Automation and exact packaged Client-to-Editor
  end-to-end coverage on macOS Apple Silicon and Windows x64.

## Packaging

The GitHub installation assets contain complete plugin source, the matching
standalone Client, and the native UE 5.7 Bridge binary. Separate Fab source
assets contain the same source and Client without UE-generated `Binaries`,
`Intermediate`, or `Saved` output. Release automation verifies that each
GitHub package derives from its Fab source package without source drift.

## Current limits

- Runtime UI automation, animation/navigation editing, automatic Blueprint
  layout, and cross-Graph execution expansion remain outside 0.7.
- Editor Context returns an explicit unresolved result when the active surface
  has no exact supported Domain Target.
- Other Unreal Engine versions, operating systems, and architectures have not
  completed the 0.7 native acceptance path.

## macOS security notice

The bundled agent-invoked Client and Bridge are not signed with a Loomle
Developer ID certificate or notarized by Apple. macOS Gatekeeper may therefore
require explicit approval before the Client can run.

## Windows security notice

The bundled agent-invoked Client and Bridge are not Authenticode-signed.
Windows may therefore show a trust or SmartScreen warning, and restrictive
Smart App Control policies may block execution until the files are approved.
