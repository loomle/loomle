# Loomle 0.7.13

Loomle 0.7.13 fixes two Graph Patch reliability regressions found on Windows
with Unreal Engine 5.7 and verified on the official UE 5.7 and 5.8 engines.

## Graph dry-run crash fix (Issue #195)

SAL Graph dry run could terminate the Editor inside
`FMemberReference::SetGivenSelfScope` when a function call Node was
materialized against the isolated preflight Blueprint with an inconsistent or
stale member owner. Graph Patch now:

- validates every Palette action against the target context before invoking
  UE's spawner, failing closed with `resolution.palette_not_spawnable` or
  `validation.spawn_failed` instead of crashing the Editor;
- roots resolved spawners as GC roots for the complete Patch lifetime;
- restores `UClass::ClassGeneratedBy` on the duplicated sandbox classes so
  UE's self-context and Blueprint-ownership resolution sees a coherent
  context.

## Subsystem Palette identity fix (Issue #196)

Every `K2Node_GetSubsystem` creation action previously shared one SAL Palette
identity, so an exact Palette object returned by a query failed with
`resolution.palette_ambiguous` when replayed in a patch. Each
subsystem-specific action now exposes a stable unique identity by folding the
template Node's `CustomClass` into the Palette signature.

## Compatibility

SAL remains at version 3. The Client-Bridge protocol remains version 5; install
one complete 0.7.13 package so the bundled Client and Bridge remain
version-aligned. Choose the package matching the installed Unreal Engine
version.
