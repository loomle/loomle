# Loomle 0.7.2

Loomle 0.7.2 adds Blueprint Graph layout reading and movement, packages the
first reusable Blueprint-formatting skill, and improves Editor Context recovery
for real Unreal Editor windows.

## Supported environment

- Unreal Engine 5.7
- macOS on Apple Silicon
- Windows on x64
- Engine-plugin installation

## Blueprint Graph layout

- Added `with layout` Graph queries. Closed Graphs return stored node positions
  and optional stored sizes; rendered Graph Editors additionally return native
  measured node and pin geometry with explicit availability diagnostics.
- Added absolute `move ... to (...)` Graph patches with shared dry-run/apply
  planning, exact before/after effects, no-op handling, atomic rollback, and a
  single Undo step for live changes.
- Added rendered Blueprint Editor coverage for live Slate geometry, alongside
  deterministic headless measurement and fallback tests.

## Agent formatting skill

- Added the vendor-neutral `format-unreal-blueprints` Agent Skill to the plugin
  package, including layout rules, examples, and the Loomle SAL workflow.
- The first ruleset favors readable execution flow, compact data dependencies,
  and human-style placement of supporting pure nodes below their consumers.

## Editor Context fixes

- Recovered standalone Blueprint Editors from their exact native root window
  when the focused Slate child has no usable DockTab path.
- Prevented stale Blueprint UI state from inventing an EventGraph Target. When
  no owned focused Graph exists, Context safely falls back to the exact
  Blueprint Target.
- Recognized a native tabless `SLevelViewport` as Level Editor structure.
  Unsaved maps now return an explicit unresolved Target with guidance to save
  the map instead of falling through to an unknown surface.

## Packaging

- GitHub releases now publish one cross-platform complete plugin archive and
  one cross-platform Fab source archive. Promotion mechanically merges verified
  Mac and Windows artifacts from the same commit without rebuilding binaries.

## Compatibility

SAL v3 continues to use Client–Bridge protocol version 3. This release remains
supported on Unreal Engine 5.7 and does not declare Unreal Engine 5.8 support.

## macOS security notice

The bundled agent-invoked Client and Bridge are not signed with a Loomle
Developer ID certificate or notarized by Apple. macOS Gatekeeper may therefore
require explicit approval before the Client can run.

## Windows security notice

The bundled agent-invoked Client and Bridge are not Authenticode-signed.
Windows may therefore show a trust or SmartScreen warning, and restrictive
Smart App Control policies may block execution until the files are approved.
