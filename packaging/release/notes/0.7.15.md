# Loomle 0.7.15

Loomle 0.7.15 keeps Blueprint dry-run validation in the background, restores
native Create Event delegate selection, and adds resident Unreal Asset
lifecycle guidance for the Python fallback. It supports Unreal Engine 5.7 and
5.8 on macOS Apple Silicon and Windows x64.

## Headless Blueprint Graph preflight

- Graph Patch continues to duplicate and compile a transient Blueprint sandbox
  so dry run and real apply exercise the same native Unreal validation path.
- Node creation now invokes the resolved `UBlueprintNodeSpawner` through a
  headless path while preserving exact object bindings, grid placement,
  analytics, and Blueprint structural-modification behavior.
- A Palette action that resolves to an existing singleton Event or bound Node
  now fails with a structured `resolution.palette_not_spawnable` diagnostic
  instead of navigating to that Node and opening the transient Blueprint.
- Native regression coverage verifies that dry run does not request or open an
  Asset Editor, register a transient Blueprint as edited, or change the active
  Slate window or keyboard focus.

## Create Event delegate selection

- Exact Create Event Node schema advertises
  `SetDelegateFunction(FunctionName)`.
- Preflight resolves the function in the Node's native scope and checks the
  connected delegate signature and Unreal bindability without guessing.
- Apply stores the Blueprint function name and Guid through Unreal's native
  reconciliation path; repeated selection is an idempotent no-op.

## Unreal Asset lifecycle guidance

- Adds the resident `manage-unreal-assets-with-python` skill for factory-backed
  create/reuse, property editing, duplication, and native in-project
  rename/move workflows.
- Requires Asset SAL preflight and verification, exact-package persistence,
  collision-safe behavior, and explicit referencer and redirector reporting.
- Treats cross-project migration as a separate higher-risk workflow with
  dependency-closure and unrelated-save caveats.

## Compatibility

The Client-Bridge protocol remains version 6. Install one complete 0.7.15
package so the bundled Client and Bridge remain version-aligned, and choose the
package matching the installed Unreal Engine version.

## macOS security notice

The bundled agent-invoked Client and Bridge are not signed with a Loomle
Developer ID certificate or notarized by Apple. macOS Gatekeeper may therefore
require explicit approval before the Client can run.

## Windows security notice

The bundled agent-invoked Client and Bridge are not Authenticode-signed.
Windows may therefore show a trust or SmartScreen warning, and restrictive
Smart App Control policies may block execution until the files are approved.
