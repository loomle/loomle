# Loomle 0.7.5

Loomle 0.7.5 makes Graph patches resilient to Unreal Engine Pin
reconstruction and lets the resident Blueprint-formatting workflow acquire
authoritative live geometry through Loomle's public Editor controls.

## Supported environment

- Unreal Engine 5.7
- macOS on Apple Silicon
- Windows on x64
- Engine-plugin installation

## Resilient Graph mutation

- Fixed Graph mutations whose native Schema callbacks can synchronously
  reconstruct Pins while disconnecting, connecting, breaking links, writing
  defaults, or inserting compound nodes.
- Carried stable node-and-Pin identity across those native mutation boundaries,
  re-resolved the current Pins between ordered statements and insertion stages,
  and returned structured diagnostics instead of dereferencing retired Pins.
- Added deterministic coverage for a `ForEachLoopWithBreak` stable-reference
  disconnect dry run, ordered disconnect and reconnect, live mutation with
  Undo, and source-graph isolation.

## Precise Blueprint formatting

- Updated the resident formatting workflow to resolve the canonical Graph with
  an exact Blueprint query when that Graph is not already active.
- When authoritative geometry requires opening and focusing that exact Graph,
  the workflow now names the target, asks for confirmation, uses Loomle's public
  `editor` call, verifies the focused context, and retries the live geometry
  query.
- The workflow leaves the opened Graph available for visual verification unless
  the user asks to close it.

## Compatibility

SAL remains at version 3 and the Client–Bridge protocol remains at version 4.
This maintenance release does not change the Client–Bridge compatibility
boundary. Install one complete 0.7.5 platform package so the bundled Client and
Bridge remain version-aligned.

This release remains supported on Unreal Engine 5.7 and does not declare Unreal
Engine 5.8 support.

## macOS security notice

The bundled agent-invoked Client and Bridge are not signed with a Loomle
Developer ID certificate or notarized by Apple. macOS Gatekeeper may therefore
require explicit approval before the Client can run.

## Windows security notice

The bundled agent-invoked Client and Bridge are not Authenticode-signed.
Windows may therefore show a trust or SmartScreen warning, and restrictive
Smart App Control policies may block execution until the files are approved.
