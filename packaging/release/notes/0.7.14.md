# Loomle 0.7.14

Loomle 0.7.14 completes the Scene/PCG Domain family: the `level`, `pcg`, and
`pcg_component` Domains move from the coordinated Query-only release candidate
to authored mutation, save, read-only Python projection, a shared async
execution kernel, a typed PCG execution frontend, and a gated authored
`pcg_component` edit surface. Verified on the official UE 5.7 and UE 5.8
engines (macOS arm64).

## Protocol version 6

The Client-Bridge protocol is now version 6. `level`, `pcg`, and
`pcg_component` canonical Targets are admitted to `PatchTarget`, and the
Python `python.run`/`python.poll` result admits the `sal.object()` projection
annex. Install one complete 0.7.14 package so the bundled Client and Bridge
remain version-aligned.

## Level authored mutation and save

- `set`/`reset` of certified scalar Actor and Component fields with exact
  schema, dry-run planning, one top-level transaction, and rollback;
- the compound `SetActorTransform` invoke (location/rotation/scale arrays,
  each optional and defaulting to the native value);
- Palette-backed Actor and instance Component lifecycle (`add` to
  `arena.Actors` or `@actor.Components`, exact `remove`), with WorldSettings,
  LevelScriptActor, and PCG-managed Actors protected;
- a terminal map `save` for the Level-owned closure with a fail-closed
  derived-state guard while PCG-managed projections cannot be inventoried;
  World Partition external-Actor closure enumeration remains a release gate
  and fails closed.

## PCG authored mutation and save

- Palette-backed Node creation (`add` through the read-only
  `palette_entries` Query), exact Node `remove` (default input/output Nodes
  protected), and exact output/input Pin `connect`/`disconnect`;
- graph-owned Settings `set`/`reset` through the public change delegate and
  absolute `move`;
- a terminal Graph package `save` that persists only the outermost package
  owning the exact Graph Target, with advisory dry run and clean-closure
  no-op.

## Python `sal.object()` read-only projection

- `sal.object(value)` marks a UObject in a script result; the Bridge replaces
  each marker in place with an independent canonical SAL exact Query result
  produced by the same Domain adapters as `sal_query`, and reports the
  `projection` annex (`complete`, `marked`, `projected`);
- records carry `status` (`projected`, `unsupported`, `stale`, `ambiguous`,
  `failed`) and `relation` (`exact`, `authored_source`); PIE/SIE duplicates
  project `authored_source` only with a uniquely proven source-map ActorGuid;
- a new `projection.*` diagnostic layer is registered.

## Shared async kernel and typed PCG execution

- the frontend-neutral `FLoomleAsyncKernel` owns the shared execution
  lifecycle (namespaced opaque ids, the outer status machine, continuation,
  poll, bounded retention, no-replay, lost-on-shutdown) extracted from the
  Python fallback without changing Python behavior;
- the Bridge-private `FTypedPcgWorldRegistry` normalizes typed-PCG World
  selectors (`editor`, or `pie` with `play`/`simulate` and `pieInstance`),
  tracks World incarnation epochs, and issues source-bound opaque tickets
  with stale rejection;
- the `FTypedPcgExecutionCoordinator` admits one Editor-World `generate` per
  validated selector + ticket + canonical `pcg_component` source, captures
  the lossless native task id, and observes terminal generation; an
  unadmitted native task completes honestly as failed with
  `runtime.pcg_generation_failed`.

## `pcg_component` authored edits under the async edit guard

- the canonical Target enters `PatchTarget`; certified scalar edits (the
  `Seed` field `set`/`reset`) apply inside one top-level transaction gated by
  a fail-closed async edit guard: the Component must be idle before and
  after, and a native notification that starts an asynchronous PCG task
  inside the transaction rolls the change back
  (`capability.pcg_async_unproven`);
- `pcg_component` never saves; a terminal `save` is a valid level-owned
  no-op.

## Compatibility

SAL remains at the nine-Domain structural catalog with protocol v6. Choose
the package matching the installed Unreal Engine version (UE 5.7 or UE 5.8).
