# Loomle 0.7.3

Loomle 0.7.3 makes professional Agent Skills a native part of the Loomle MCP
experience. Agents can discover and load packaged workflow guidance on demand,
without requiring users to install a separate host-specific Skill.

## Supported environment

- Unreal Engine 5.7
- macOS on Apple Silicon
- Windows on x64
- Engine-plugin installation

## MCP-managed Agent Skills

- Added the read-only `agent_skill` MCP call. With no arguments it lists every
  resident Skill and its task-matching description; with an exact name it
  returns the complete Skill instructions and Markdown references.
- Embedded the canonical Agent Skill sources into the self-contained
  TypeScript Client at build time, with generated-catalog drift checks and
  packaged smoke coverage.
- Kept Skills vendor-neutral: their workflows use Loomle's public MCP calls and
  portable SAL text rather than depending on one agent host's tool-call syntax.
- Included resident Skills in both Fab source and complete GitHub packages, with
  release gates that reject missing or altered Skill content.

## Blueprint formatting workflow

- Made `format-unreal-blueprints` discoverable directly through MCP when a
  graph-formatting task matches its description.
- The workflow combines live layout geometry, semantic graph reading,
  move-only dry runs, absolute placement, and post-apply verification to pursue
  compact, near-human Blueprint layouts without changing graph behavior.

## Documentation and website

- Reframed Loomle MCP around three core SAL calls—`sal_schema`, `sal_query`, and
  `sal_patch`—that operate across supported Unreal objects without expanding
  the public interface for every capability.
- Added a dedicated Resident Agent Skills section with a same-graph Blueprint
  layout comparison that demonstrates domain expertise loaded on demand.
- Added complete documentation for Skill discovery, loading, packaging, and the
  Blueprint formatting workflow.

## Compatibility

SAL v3 continues to use Client–Bridge protocol version 3. This release remains
supported on Unreal Engine 5.7 and does not declare Unreal Engine 5.8 support.

## macOS security notice

The bundled agent-invoked Client and Bridge are not signed with a Loomle
Developer ID certificate or notarized by Apple. macOS Gatekeeper may therefore
require explicit approval before the Client can run.

## Windows security notice

The bundled agent-invoked Client and Bridge are not Authenticode-signed.
Windows may therefore show a trust or SmartScreen warning, and restrictive
Smart App Control policies may block execution until the files are approved.
