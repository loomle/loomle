# Loomle 0.7.12

Loomle 0.7.12 keeps the Unreal, SAL, Client, and Bridge behavior of 0.7.11.
This maintenance release updates the author URL embedded in the MCP Registry
and Claude Desktop Extension manifests to the official Loomle GitHub
organization profile, matching Anthropic's directory submission requirement.

No Unreal Engine behavior, Client–Bridge protocol, or SAL behavior changed.
The Client–Bridge protocol remains at version 5.
