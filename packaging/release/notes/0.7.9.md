# Loomle 0.7.9

Loomle 0.7.9 adds official Unreal Engine 5.8 support, introduces the guarded
Unreal Python fallback, and publishes engine-specific complete packages for UE
5.7 and UE 5.8.

## Supported environment

- Unreal Engine 5.7 and 5.8
- macOS on Apple Silicon
- Windows on x64
- Engine-plugin installation

## Unreal Engine 5.8

- Supports UE 5.8 JSON, Find-in-Blueprint, StateTree, Widget, and editor API
  behavior while retaining the same agent-facing SAL behavior on UE 5.7.
- Uses each engine's `UnrealEditor.modules` manifest as the authority for the
  Bridge module filename, including UE 5.8's `libUnrealEditor-LoomleBridge.dylib`.
- Runs the complete Automation and packaged end-to-end gates independently on
  UE 5.7 and UE 5.8.

## Unreal Python fallback

- Adds one guarded `python` MCP tool for narrow Unreal Editor operations that
  are not yet represented by a native Loomle interface.
- Supports synchronous results and explicit polling for asynchronous execution,
  while binding each execution to the Editor runtime that created it.
- Validates input, result shape, execution ownership, timeouts, cancellation,
  and runtime loss instead of exposing an unrestricted background interpreter.

## Blueprint and Widget reliability

- Retains duplicated Blueprint source objects during garbage collection so
  graph and Widget sandbox operations cannot lose their source mid-mutation.
- Resolves Widget event Palette references through their public member parent
  class and signature identity.

## Packages and updates

- Publishes one shared source package for Fab and separate complete GitHub
  packages for UE 5.7 and UE 5.8.
- Each complete package contains the verified Mac and Windows Bridge binaries
  plus both self-contained Clients.
- The Client reads the installed plugin descriptor and discovers updates only
  from the release asset matching that engine version.

## Compatibility

SAL remains at version 3. The Client–Bridge protocol is version 5; install one
complete 0.7.9 package so the bundled Client and Bridge remain version-aligned.
Choose the package matching the installed Unreal Engine version.

## macOS security notice

The bundled agent-invoked Client and Bridge are not signed with a Loomle
Developer ID certificate or notarized by Apple. macOS Gatekeeper may therefore
require explicit approval before the Client can run.

## Windows security notice

The bundled agent-invoked Client and Bridge are not Authenticode-signed.
Windows may therefore show a trust or SmartScreen warning, and restrictive
Smart App Control policies may block execution until the files are approved.
