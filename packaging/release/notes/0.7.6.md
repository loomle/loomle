# Loomle 0.7.6

Loomle 0.7.6 preserves Blueprint-owned functions and designer members when
Graph Palette actions are resolved inside a patch sandbox, and expands the
resident Blueprint-formatting workflow with explicit, evidence-driven topology
follow-ups.

## Supported environment

- Unreal Engine 5.7
- macOS on Apple Silicon
- Windows on x64
- Engine-plugin installation

## Blueprint member Palette actions

- Fixed Graph Patch preflight for Blueprint-owned functions and Widget
  Blueprint designer members whose Palette actions were discovered from the
  live Blueprint but previously became unavailable in the duplicated sandbox.
- Kept live capability discovery separate from sandbox mutation, then mapped
  Blueprint-owned function and property references to their sandbox
  equivalents before invoking Unreal Engine's native node spawners.
- Preserved exact-schema, dry-run, live-apply, stable-identity, source-isolation,
  and Undo behavior, with distinct diagnostics for missing and non-spawnable
  Palette actions.
- Added regression coverage for two Widget Blueprint functions and a designer
  widget getter across both dry-run and live Graph patches.

## Blueprint formatting topology guidance

- Added a separate, explicitly authorized workflow for duplicating cheap local
  variable getters and adding reroute nodes after a move-only formatting pass
  reports a concrete topology improvement.
- Added measured guidance for comparing shared getter fan-out with
  consumer-local getters, while avoiding cosmetic duplication of potentially
  expensive pure function calls.
- Added exact-edge rewiring, stable node-and-Pin identity, minimal-knot routing,
  live-geometry verification, and post-change validation rules for topology
  follow-ups.

## Compatibility

SAL remains at version 3 and the Client–Bridge protocol remains at version 4.
This maintenance release does not change the Client–Bridge compatibility
boundary. Install one complete 0.7.6 platform package so the bundled Client and
Bridge remain version-aligned.

This release remains supported on Unreal Engine 5.7 and does not declare Unreal
Engine 5.8 support.

## macOS security notice

The bundled agent-invoked Client and Bridge are not signed with a Loomle
Developer ID certificate or notarized by Apple. macOS Gatekeeper may therefore
require explicit approval before the Client can run.

## Windows security notice

The bundled agent-invoked Client and Bridge are not Authenticode-signed.
Windows may therefore show a trust or SmartScreen warning, and restrictive
Smart App Control policies may block execution until the files are approved.
